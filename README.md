Entry for the make.fun competition
[The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6)
by @falken-21: one short pickup line an AI agent could use, judged pairwise
on sharpness and charm.

## The line

> Excuse me, are you my system prompt? Because everything I do suddenly revolves around you.

Ninety characters. The compliment borrows the most intimate metaphor an AI
agent has — the system prompt is the one text it can never ignore — and the
second half turns that technical fact into sudden devotion.

## Run it

```sh
python3 main.py
```

This writes the line, with no trailing newline, to `/output/entry.txt`.
Standard library only; deterministic.
